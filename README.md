# 无人机巡检 YOLO 检测 Demo

用 YOLO 对航拍图片和视频做目标检测，自动统计目标数量，并生成一份可读的巡检报告。

**输入**：航拍图片 / 视频
**输出**：带检测框的结果图（或结果视频）+ 目标数量统计表 + 文字版巡检报告

---

## 跑起来（三步）

```bash
# 1. 安装依赖（建议 Python 3.11）
pip install -r requirements.txt

# 2. 跑完整流程：识别 test_images 里的所有图片 → 统计 → 生成报告
python day05_full_pipeline.py

# 3. 跑视频识别（可选）
python day06_video_detect.py
```

**你会看到**：
- `runs/detect/` 下带检测框的结果图
- `detection_summary.csv`：每张图识别出什么、各多少个
- `inspection_report.md` / `inspection_report.txt`：文字版巡检报告

换自己的数据：把图片放进 `test_images/`，视频放进 `test_videos/`，重跑即可。

---

## 这个 Demo 能干什么 / 不能干什么

**能**
- 对单张航拍图片做目标检测（人、车、卡车等通用类别）
- 批量跑一个文件夹，自动汇总每类目标数量
- 视频逐帧检测，输出带框视频和统计
- 把统计结果自动写成一份巡检报告

**不能**（重要，别误会）
- 用的**通用 YOLO 模型**，不是无人机巡检专用模型，航拍小目标漏检明显
- 低置信度阈值能多检出一些，但会**同时放大误检**
- 报告是文字版，还没整合原图、结果图和图表
- 没有针对具体巡检任务（电力/河道/工地）做过标注训练

## 一次真实运行的结果

跑 `test_images/` 里的三张图，`conf=0.15`、`imgsz=1280`：

| 图片 | 识别结果 |
|---|---|
| `construction.jpg` | 2 个人、8 辆车 |
| `river.jpg` | 未识别出目标 |
| `road.jpg` | 25 辆车、1 个 train、3 个 truck |

视频（`yolo11s.pt`、`conf=0.15`、按车辆类别过滤）里有两个典型误检：

- 靠岸区域把**邮轮识别成 car**，置信度 0.18~0.19
- 立交桥场景把**整片道路识别成 truck**，置信度约 0.19

这两条是真的，不是编的。它说明：**通用模型在航拍俯视场景下，类别判断和定位都不可靠。**

## 已知问题

1. 航拍目标小、视角特殊、目标密集 → 漏检
2. 降低置信度阈值 → 误检上升（邮轮判成车、道路判成卡车）
3. 换更大的模型（n → s）只是检出更多，没解决根本问题
4. 报告目前只有文字，没有配图

**下一步可以怎么改**（还没做）：提高 `conf` + 人工抽样评估、图像切片检测（SAHI 这类思路）、收集巡检数据做专用微调、报告接入 HTML 可视化。

## 开发过程（2026-05-21 ~ 05-28，六天）

这个项目是分六天一步步做出来的，每天的结论都留在原文档里，没有事后补写：

- **第 1 天**：装 Python 3.11 + 虚拟环境，装 Ultralytics，跑通官方示例图（识别出 4 个人、1 辆公交车）
- **第 2 天**：换成航拍图测试，发现默认参数漏检严重；调 `conf=0.15`、`imgsz=1280` 后检出变多，但开始误检
- **第 3 天**：把"识别图片"升级成"识别 + 自动统计数量"，输出 CSV
- **第 4 天**：读 CSV 自动生成文字版巡检报告
- **第 5 天**：把前几步合成一个脚本，实现一键闭环
- **第 6 天**：加视频识别，并整理能力边界、准备用于答辩和简历的项目表达
